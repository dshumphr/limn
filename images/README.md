# images

Generated images are stored here. Each generation or edit produces three files:

- `YYYYMMDD_HHMMSS.png` — small source image
- `YYYYMMDD_HHMMSS_upscaled.png` — 4× upscaled version (for display)
- `YYYYMMDD_HHMMSS.json` — metadata (original prompt, improved prompt, mode, paths)

File naming ensures alphabetical and chronological order are identical.
